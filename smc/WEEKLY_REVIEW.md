# Weekly review template

Week: `YYYY-Www` · Pair: · Reviewer: · Rule book version:

1. **Trades this week** (from the journal): count per strategy, total R, win rate. Sample so far: (n). Below 100 trades per strategy, every number is statistically weak.
2. **Rule broken most often** (from `rule_violations`): which, how many times, what it cost in R.
3. **Best expectancy** this week and to date, per strategy (journal), next to the backtest's figure for the same strategy.
4. **Engine vs journal**: setups the engine flagged that were not taken, and trades taken that the engine did not flag.
5. **Devil's advocate**: one case where a rule would have lost money, and whether hindsight was used anywhere.
6. **To test next** (one or two, each with a written yes / no definition before any data is looked at).
7. **Changes**: none, or a `CHANGELOG.md` entry (version, rule, before, after, why, data it was tested on).
